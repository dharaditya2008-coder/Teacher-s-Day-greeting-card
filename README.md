# Teacher's Day Interactive Card

Open `index.html` in Chrome on PC or mobile.

## Edit in Visual Studio Code
- Main design/content: `index.html`
- Photos: replace `images/sir-1.jpg` and `images/sir-2.jpg`
- To change the greeting, edit the text inside `index.html`.
- No server, Node.js, Python, or internet connection is required.

The page is intentionally built with plain HTML, CSS and JavaScript so it is easy to edit.
